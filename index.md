# Drumshift

Drumshift moves drum MIDI from one sample library's note layout to another. Drop a `.mid` file, pick the layout it was written for and the one you play, and drag the result into your DAW.

## Support

Found a wrong note, a missing library or a bug? [Open an issue](https://github.com/mirosblack/drumshift/issues/new) and describe the source and target layouts, and attach the MIDI file if you can.

**Where are my converted files?** In `~/Music/Drumshift`. You can also drag any row from the list straight into Finder or your DAW.

**Can I add my own layout?** Yes. Drop one of these onto the window:
- a Studio One song or `.vstpreset` with a MidiRemap map from General MIDI,
- a Reaper MIDI note-name `.txt` file,
- a text table with lines like `36 -> 24` (GM note -> library note).

## Privacy

See the [privacy policy](privacy.html). Short version: Drumshift collects nothing.
